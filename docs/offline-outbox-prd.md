# SendHere 离线发件箱 PRD

## 目标

用户可在目标设备离线时发送文字和文件。内容立即出现在发送方会话中，任务在本机持久化，目标恢复连接后自动投递。

## 状态

- `等待设备上线`：任务已安全写入本机发件箱，目标没有可用会话。
- `正在发送`：已建立会话，文件正在传输。
- `已送达`：接收端已接受文字或文件上传请求。
- `发送失败`：一次投递失败；保留任务及本地文件，后续连接时重试。

## 约束

- 文件加入发件箱时复制到应用支持目录，不能依赖 Finder 原路径。
- 每台设备维护独立、有序的任务列表；重启后恢复。
- 发件箱只以接收端已接受数据作为“已送达”，不把用户是否打开文件作为默认确认。
- 离线时文本、附件、发送按钮可用；发送动作仅排队。
- 任务在设备 `clientConnected` 后自动按创建顺序发送。
